# 表格 WYSIWYG Smoke

打开本文件切换到 WYSIWYG 模式，按清单逐项操作。本文件只含公开示例，可作为可重复验收样例。

正常表格：内联格式、空单元与四种对齐（左、中、右、默认）：

| 功能 | 说明 | 状态 | 备注 |
| :--- | :---: | ---: | --- |
| **粗体**与*斜体* | 单元内联格式显示与编辑 | done |  |
| code 内管道 `` `a\|b` `` | 反斜杠转义不改变列数 | wip | 空单元仍可聚焦 |
| [链接](https://example.com) | 只编辑标签，不导航 | plan | ~~删除线~~保留 |

仅表头、无数据行、外侧管道可有可无：

| 只有表头 | 空数据 |
| --- | --- |

宽表与长路径：窄窗口内表格应横向滚动，长中文与长 code 路径软换行，不撑宽编辑器：

| 模块 | 路径 | 说明 |
| --- | --- | --- |
| 长代码路径 | `src/features/deeply/nested/directory/structure/with/long/path/component.really-long-name.tsx` | 长中文文本应在单元内软换行而不是撑开表格，720px 窗口内行列与对齐工具仍可达 |
| 系统路径 | `/usr/local/lib/very/long/system/path/to/some/library/file.so` | 明暗两种外观下均可读 |

中文与转义组合：输入 `|`、反斜杠、反引号均不得改变列数或串到相邻单元：

| 输入 | 期望 |
| --- | --- |
| 中文\|竖线 | 仍是一个单元 |
| 反斜杠开头 `\|` | 保留原文 |
| HTML `<b>加粗</b>` | 按文字显示，不执行、不导航 |
| 空单元 |  |

行列不齐的不支持表格保持源码岛，不被吞并或截断：

| 不齐 | 表格 |
| --- | --- |
| 多 | 余 | 单元 |

列表内表格不做结构化支持，保持原文：

- 列表项
  | 缩进 | 表格 |
  | --- | --- |
  | 保持 | 源码 |

编辑任一表格时，下方前后正文必须逐字保留。

> 引用块原样保留。

```text
代码围栏与表格无关，任何表格编辑不得改动此处。
```

尾段：保存后关闭重开，仍应是有效 Markdown 且表格完整。
