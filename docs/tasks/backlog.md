# Backlog

这里保存尚未承诺实施的候选事项，不代表优先级或开发计划。事项进入 `current.md` 前，应先明确范围；涉及用户可观察行为时创建 Feature Spec。

## 产品与技术发现

- 明确 Markdown 左右分栏与所见即所得模式的源码无损、安全边界和切换语义。
- 明确列块数字序列填充的起始值、步长、前导零及扩展格式范围。
- 明确 Mermaid 本地编辑与预览范围和安全约束。
- 评估超过 50 MiB 文件的只读或分块编辑方案。

## 候选垂直切片

- 增加未保存关闭保护：关闭标签或窗口时提供保存、放弃或取消；保存失败不得继续关闭。
- 增加多标签会话：每个标签独立维护内容、后端可信文档状态、保存状态与关闭保护。
- 增加列块编辑：矩形选择、批量删除、多行粘贴与数字序列填充。
- 增加代码文本识别与最小语法高亮。
- 增加 Markdown 源码与本地预览左右分栏。
- 增加可与左右分栏切换且保持源码无损的 Markdown 所见即所得模式。
- 增加 Mermaid 编辑与预览。
- 增加其他传统编码与 GB18030 支持。

已完成的另存为/首次保存是当前冲突解决任务与关闭保护的前置；冲突解决和关闭保护又是多标签的前置。该关系只用于避免提前构建错误抽象，不代表本文件中的候选事项已承诺；任何候选进入 `current.md` 前仍需形成对应 Feature Spec 并确认范围。
