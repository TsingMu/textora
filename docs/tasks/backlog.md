## 编辑器查看与未保存文档格式

- 在编辑器上方显示横向列标尺，并在右下角显示当前光标的行号与列号。列标尺每 5 列显示一级明显刻度，每 10 列显示更强的明显刻度；进入 Feature Spec 时需补充横向滚动、软换行、Tab 与宽字符下标尺及光标列号的计算和对齐规则。
- 在 macOS 顶部菜单栏的 `View` 等合适菜单中增加自动换行开关。开启时，超过编辑区宽度的长行只做软换行显示；关闭时保持单行并通过横向滚动查看。切换不得插入实际换行、修改文档内容或触发未保存状态。该查看偏好全局保存，应用重启后继续生效。
- 在 macOS 顶部菜单栏的合适菜单中增加未保存文档的显示格式选项，例如 Java、SQL 等语法模式。选择只作用于当前未保存标签，用于语法高亮，并在该标签首次保存时按所选格式建议默认文件后缀；不同未保存标签可独立选择，选择结果不作为以后新建标签的默认值。保存后，文档格式应改由实际文件名或后缀识别；进入 Feature Spec 时需确定支持的格式清单、格式到默认后缀的映射、无后缀和用户手动输入其他后缀时的处理规则。
- 列标尺、光标位置显示和自动换行等查看偏好采用全局设置并持久化到应用重启后；未保存标签的文档格式选择属于标签临时状态，不纳入全局默认。
- 将 Markdown 源码工具栏现有的 `Format JSON` 改为通用 `Format`。用户点击后，根据光标所在闭合 fenced code block 的语言标记自动选择格式化器，并且只格式化该代码块，不批量修改文档内其他代码块。首期保留 JSON，并扩展支持 JavaScript、TypeScript、YAML、SQL、Java、Python 与 Shell；无法识别语言、语言暂不支持、代码块未闭合或内容语法无效时，应提示原因且不得修改源码。继续沿用显式触发、单次事务和一次撤销恢复的安全边界，不在输入、粘贴或保存时自动格式化；进入 Feature Spec 时需确定各语言标记及别名、格式化风格、本地格式化器与依赖方案，以及 Preview 左侧源码和 WYSIWYG 的模式边界。
