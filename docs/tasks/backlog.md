# Backlog

这里保存尚未承诺实施的候选事项，不代表优先级或开发计划。事项进入 `current.md` 前，应先明确范围；涉及用户可观察行为时创建 Feature Spec。

## 产品与技术发现

- 明确外部文件变更实时同步语义：已打开文件被其他应用修改、替换、删除或移动后如何检测；无本地修改时是否自动刷新内容与编码/换行元数据；存在未保存修改时如何提示并复用冲突解决，避免静默覆盖用户编辑。
- 评估超过 50 MiB 文件的只读或分块编辑方案。

## 候选垂直切片

- 增加外部文件变更实时同步：监听已打开文件的磁盘变化，无本地修改时及时重新读取并在当前标签展示最新内容；存在未保存修改、文件被删除/移动、重新读取失败或编码不再受支持时，不静默替换编辑内容，改为显示可操作的冲突或错误提示。
- 增加其他传统编码与 GB18030 支持。
