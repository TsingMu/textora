## 目标与非目标

用户能在当前列左右插入空列并安全删除指定列，所有行与对齐同步保持矩形，剩余内容和表格外原文保留。

非目标：不调整列宽、不拖拽/排序、不合并、不删最后一列/整表，不新增新建表格。

粒度依据：本项只交付上述一个契约或用户行为，包含必要实现、测试与自检，原则上可在一次聚焦实施会话稳定交付。完整回归和平台矩阵由 07 承接，不混入本项主要实现；07 本身不承担未实现主要行为。
