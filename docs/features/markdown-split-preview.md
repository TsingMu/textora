# Markdown 源码与本地预览左右分栏

> 状态：实现中（2026-08-10）

## 背景与目标

Textora 已支持 Markdown 文件的源码语法高亮，但还不能像日常写作工具那样边编辑边查看渲染结果。用户需要在保持 Markdown 源码作为权威内容的前提下，本地查看标题、列表、代码块、表格等常见 Markdown 结构的预览，减少在编辑器和外部预览工具之间来回切换。

本功能目标是提供一个最小、可安全退化的左右分栏 Markdown 预览：左侧仍是 CodeMirror 源码编辑器，右侧是从当前源码派生出的本地渲染视图。预览只用于查看，不成为保存数据源；渲染失败时不影响继续编辑和保存源码。

## 范围

- 为 Markdown 文件提供手动开启的源码/预览左右分栏视图。
- 预览内容由当前活动标签的 Markdown 源码本地派生。
- 支持常见 Markdown 结构的基础渲染：标题、段落、强调、链接文本、列表、任务列表、引用、代码块、行内代码、分隔线、表格和删除线。
- 切换标签时，分栏状态与预览内容应跟随活动标签，不污染其他标签。
- 非 Markdown 文件默认保持现有源码编辑视图，不强制显示预览。
- 预览失败或不支持的 Markdown 片段应安全退化为可编辑源码与可理解错误提示。

## 非范围

- Markdown 所见即所得编辑。
- Mermaid 图表渲染或预览。
- 导出 PDF/HTML/图片。
- 远程图片、远程脚本、远程样式或任意网络访问。
- 插件系统、自定义主题、目录大纲、脚注、数学公式、自动滚动同步等扩展能力。
- 改变保存格式、编码、换行、冲突保护或 Tauri 文件权限。

## 用户流程

1. 用户打开或另存为一个 `.md` / `.markdown` 文件。
2. Textora 识别该标签为 Markdown，并在工具栏提供 `Preview` 开关；默认仍显示现有源码编辑视图。
3. 用户在左侧编辑源码，右侧预览随源码变化更新。
4. 用户切换到其他标签后，界面显示该标签自己的编辑/预览状态。
5. 用户保存文档时，保存的仍是左侧 Markdown 源码文本。

## 行为规则与边界情况

- Markdown 源码仍是唯一权威数据源；预览 DOM 是可重建派生结果，不参与保存。
- 预览渲染必须在本地完成，不请求远程页面、脚本或样式。
- 首版预览入口为 Markdown 活动标签工具栏里的 `Preview` 开关；不自动打开分栏，也不在非 Markdown 文件上显示该入口。
- 分栏开关状态按标签保存在当前会话内；不写入磁盘、不作为全局偏好、不跨应用重启恢复。
- 首版不做编辑器与预览的滚动同步；左右两侧独立滚动。切换标签再切回时，可保留浏览器/组件自然保留的即时滚动位置，但这不是持久化状态。
- 原始 HTML 一律按文本转义显示，不作为 HTML 插入预览 DOM。
- Markdown 链接首版显示为文本链接样式和 URL 文本，但不触发导航、不打开外部浏览器。
- Markdown 图片首版不加载远程或本地资源，只显示 alt 文本与图片 URL 占位，避免新增网络或文件读取权限。
- 非 Markdown 标签切换回来时，不应改变 Markdown 标签的源码内容、脏状态、编码/换行设置或语言状态栏。
- 大文件规则沿用首版 50 MiB 上限；若预览明显卡顿，应优先退化或延迟预览，不影响源码编辑。
- 关闭、保存、另存为、文件缺失、冲突与未保存保护流程保持现有行为。

## 验收条件

- [ ] Markdown 文件工具栏显示 `Preview` 开关；开启后进入左右分栏，左侧源码可正常编辑，右侧显示本地渲染结果。
- [ ] 编辑标题、列表、任务列表、引用、代码块、表格和删除线等首版结构后，预览能跟随当前源码更新。
- [ ] 保存后磁盘内容仍为 Markdown 源码，不包含预览产物或格式化副作用。
- [ ] 非 Markdown 文件不被强制打开预览，普通文本与代码高亮体验不回退。
- [ ] 多标签切换时，Markdown 预览状态与源码内容相互隔离。
- [ ] 原始 HTML 被转义显示；链接不触发导航；图片不加载远程或本地资源，只显示安全占位。
- [ ] 渲染失败、不支持语法或安全策略阻断时，源码编辑和保存仍可继续。
- [ ] 功能不引入网络、shell、远程页面或宽泛文件系统权限。
- [ ] 自动化测试覆盖 Markdown 识别入口、预览开关/分栏状态、多标签隔离、源码保存不受预览影响和安全退化。
- [ ] macOS release 应用真实验收覆盖打开 Markdown、编辑后预览更新、保存源码、多标签切换和关闭保护。

## 实现拆分

Markdown 分栏预览按以下顺序拆成可连续交付的小切片，实现时优先保留现有编辑、保存和高亮行为。`docs/tasks/current.md` 同一时间只保留下一个待执行切片。

1. **确认 Markdown 源码与本地预览左右分栏规格**（本任务）：确定预览入口、分栏状态归属、滚动同步、安全策略和首版 Markdown 语法清单；不修改生产代码。
2. **建立 Markdown 预览渲染与安全退化契约**：新增本地 Markdown 渲染适配层，明确原始 HTML、链接、图片和渲染错误的处理；覆盖纯函数/组件级测试，不接入主界面状态。
3. **接入 Markdown 分栏入口与预览更新**：在 Markdown 活动标签中提供预览开关和左右分栏布局，非 Markdown 标签保持现有编辑视图；按确认后的状态归属保存分栏开关；源码变化后更新预览，多标签切换时保持各标签状态互不污染。
4. **Markdown 分栏集成验收与文档收尾**：完整自动化、release 构建和 macOS 真实应用验收；确认保存仍只写源码，规格状态改为已完成，必要时同步 README。
