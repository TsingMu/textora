# 另存为内嵌目标面板

> 状态：已确认（2026-08-04）。本规格取代当前“先选编码/换行，再进入 macOS 系统保存面板”的前置体验，但不取消既有安全保存、冲突检测和编码规则。

## 背景与目标

当前 Save As 会先弹出格式选择对话框，文件名与保存位置需要进入下一步 macOS 系统保存面板后才能修改。这个顺序让最重要的目标选择隐藏在第二步，而编码与换行这种低频选项反而占据主界面。

本功能目标是把另存为的主决策改成“保存到哪里、叫什么名字”：在当前应用内对话框中直接展示并允许修改文件名与保存位置；编码与换行不出现在另存为对话框主体，而由应用主界面右下角的可选设置决定。用户点击确认后，应用按面板里的目标以及主界面右下角当前格式设置执行既有安全保存流程。

## 范围

- Save As 与 Untitled 首次保存共用新的应用内目标面板。
- 对话框主体展示文件名和保存位置，而不是默认展示编码与换行选择。
- 文件名可以在对话框内直接编辑。
- 保存位置显示为可理解的路径或目录名称，并提供选择/更改入口。
- 应用主界面右下角提供编码与换行的可选设置入口；另存为对话框不要求用户每次选择格式。
- 编码与换行根据应用主界面右下角的当前选择自动确定：
  - 已打开文档默认沿用当前可信文档的编码与换行。
  - Untitled 默认使用 UTF-8 与 LF。
  - Mixed 换行仍需要用户明确选择 LF 或 CRLF 后才能保存。
- 用户在应用主界面右下角可以显式选择 UTF-8、UTF-8 BOM、GBK，以及 LF 或 CRLF。
- 点击确认后复用既有安全保存、只读、冲突、目标缺失、编码不可表示、编码歧义和大小限制保护。

## 非范围

- 最近目录、收藏目录、目录浏览器或完整文件管理器。
- 自动追加、修正或强制文件扩展名。
- 批量另存为或多标签批量保存。
- 新增偏好持久化。
- 放宽前端文件系统权限、shell 权限、网络权限或直接读写用户文件。
- 重新设计普通保存、打开文件、保存冲突解决或未保存关闭保护。

## 用户流程

1. 用户点击 Save As，或在 Untitled 文档点击 Save。
2. 应用打开新的另存为目标面板。
3. 面板主体显示默认文件名与保存位置。
4. 用户可直接修改文件名，也可通过位置选择入口更改保存目录。
5. 如果无需调整编码和换行，用户直接确认保存。
6. 如需调整格式，用户先在应用主界面右下角选择编码与换行，再从另存为对话框确认保存。
7. 保存成功后，当前会话关联到实际目标，标题与状态栏显示新文件信息。
8. 用户取消时，内容、路径、显示名、未保存状态和磁盘文件均保持不变。

## 行为规则与边界情况

- 默认文件名规则沿用已完成的 `save-as-target-selection`：已有文档使用当前显示名，Untitled 使用 `Untitled`。
- 默认保存位置：
  - 已有文档优先显示当前文件所在目录。
  - Untitled 可使用系统默认目录，或在选择位置前显示清晰的未选择状态。
- 保存位置必须来自用户明确选择或已可信的当前文档父目录；前端不得获得宽泛文件系统能力。
- 若实现需要前端暂存目标信息，应优先使用 Rust 侧生成的受限目标草稿或目录授权，而不是让前端提交任意可写路径并直接写盘。
- 文件名为空、包含 macOS 不允许的路径分隔含义、或目标位置未确定时，不允许确认保存，并给出可理解提示。
- 如果用户选择的位置与文件名组成当前原路径，仍按普通保存路径处理，不绕过指纹、冲突和只读保护。
- 如果目标已存在，覆盖确认与之后的冲突复核仍沿用既有安全保存语义。
- Mixed 换行不能被静默保存为 Mixed；若当前内容为 Mixed，应用主界面右下角设置应提示用户选择 LF 或 CRLF，另存为确认前也应阻止未决格式直接保存。
- GBK 不可表示或编码歧义时，保存必须失败并保留内容与未保存状态。
- 取消目录选择、关闭面板或按 Escape 均视为取消本次另存为，不改变当前会话。

## 验收条件

- [ ] Save As/Untitled Save 打开的主对话框直接显示文件名与保存位置。
- [ ] 默认状态下另存为对话框不要求用户选择编码与换行；确认保存会使用应用主界面右下角当前确定的编码与换行。
- [ ] 应用主界面右下角可以打开或调整编码与换行设置，并能覆盖默认选择。
- [ ] 用户修改文件名和保存位置后保存成功，当前会话关联到实际目标，后续普通保存写入该目标。
- [ ] 用户取消面板或取消位置选择后，内容、路径、显示名、未保存状态和磁盘文件均保持不变。
- [ ] Mixed 换行必须明确选择 LF 或 CRLF 后才能保存。
- [ ] 选择当前原路径不会绕过普通保存冲突与只读保护。
- [ ] 只读源文件可以另存为到可写目标。
- [ ] 自动化测试覆盖目标面板默认值、文件名修改、位置选择取消、格式设置收起/展开、自动格式选择、Mixed 阻断、成功关联与取消恢复。
- [ ] macOS 真实交互验收确认应用内面板可完成指定文件名与保存位置的另存为。

## 依赖与约束

- 依赖已完成的 `docs/features/save-as-and-first-save.md` 与 `docs/features/save-as-target-selection.md`。
- 遵守 `docs/ARCHITECTURE.md` 的最小权限边界：前端不得获得宽泛文件系统、shell、网络或任意本地读写能力。
- 遵守 D-005/D-006 的编码边界：UTF-8、UTF-8 BOM 与严格 GBK/CP936；GBK 不可表示或无法无损重开时必须拒绝。
- 不改变 50 MiB 文件上限、二进制 IPC 和安全保存核心。
- 本功能是多标签 Save As 体验的前置修正；多标签只应复用本规格形成的单标签语义。

## 开放问题

- 保存位置在未选择时是否显示完整系统默认目录，还是显示“选择保存位置…”占位文本。
- 位置选择入口采用“选择文件夹”还是“选择保存位置”文案。
- 应用主界面右下角设置入口使用弹出菜单、展开区域还是独立小面板。
