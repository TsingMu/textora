# 列块编辑

> 状态：已完成（2026-08-07）

## 背景与目标

Textora 的目标之一是把用户在 Windows 内网工作中依赖 UltraEdit/Notepad++ 完成的列块处理带到 macOS。多标签、保存与关闭保护完成后，下一阶段需要在现有 CodeMirror 编辑器上建立可安全扩展的列块编辑能力，让用户能按矩形区域选择多行中的同一列范围，并在后续切片中执行批量删除、粘贴与数字序列填充。

本功能目标是交付一个以普通文本为权威源的列块编辑基础：矩形选择应可见、可取消、参与撤销/重做，并且所有编辑结果都只是普通文本内容变化，继续复用既有脏状态、保存、编码、换行、冲突和关闭保护。

## 范围

- 在编辑器中支持使用 `Option` + 鼠标左键拖拽创建矩形选择。
- 矩形选择跨多行时，每一行形成独立选择范围或光标。
- 对矩形选择执行批量删除。
- 对矩形选择执行多行粘贴：剪贴板含多行文本时按选择行逐行写入；单行文本可插入到每个选择行。
- 对矩形选择执行数字序列填充：按行生成递增数字并替换或插入到选择位置。
- 列块编辑产生普通编辑事务，必须正确更新脏状态，并参与 CodeMirror 的撤销/重做。

## 非范围

- 二进制/十六进制编辑。
- 自动对齐表格、CSV 智能列识别或结构化数据编辑。
- 跨标签、跨文件或多窗口的列块操作。
- 鼠标拖拽以外的完整键盘矩形选择方案。
- 富文本、Markdown 预览或代码语义感知的列选择。
- 数字序列的十六进制、字母、日期或自定义格式；这些是否进入后续范围需另行决议。

## 用户流程

1. 用户打开或新建一个普通文本标签。
2. 用户按住 `Option` 并在编辑器中拖拽，形成跨多行的矩形选择。
3. 用户可以直接删除所选列块，或粘贴文本到每个选择行。
4. 用户可以点击工具栏 `Sequence`，或按 `⌥⌘N` 触发数字序列填充，把每一行的选择范围替换为递增数字。
5. 编辑结果显示为普通文本变化；用户可撤销/重做，也可按既有流程保存或放弃。

## 行为规则与边界情况

- 列块编辑只作用于当前活动标签，不影响后台标签或其他已打开文件。
- `Option` 拖拽是首版鼠标入口；不改变普通鼠标选择、双击选择或键盘选择的默认行为。
- 矩形选择跨越短行时，短行可在行尾形成光标；后续插入会在行尾插入，不用空格自动补齐到视觉列。
- 所有列块编辑都必须通过 CodeMirror 事务修改 Unicode 文本，由现有会话层同步为 `content` 并设置脏状态。
- 保存仍由既有 Rust 文档核心负责编码、换行、大小、冲突和原子写入；列块编辑不得绕过保存保护。
- 只读、加载、保存、另存为、冲突、文件缺失或关闭确认等禁用编辑/锁定模态期间，不允许产生新的列块编辑。
- 若粘贴行数少于选择行数，首版只允许单行文本复制到每个选择行，或多行文本与选择行数一致；其他不匹配情况应安全拒绝并保留内容不变。
- 数字序列首版采用十进制整数，起始值 `1`、步长 `1`，宽度按结束值自动确定；前导零、自定义起始值和步长留给后续切片确认。
- 数字序列首版入口为工具栏 `Sequence` 按钮，并保留编辑器快捷键 `⌥⌘N`（CodeMirror `Mod-Alt-n`）；后续如需命令面板或参数化入口，应另行拆分。

## 实现拆分

1. **接入 Option 拖拽矩形选择基础**：启用 CodeMirror 矩形选择、多选区和十字光标提示；不新增批量命令。
2. **实现列块删除**：对多选区执行删除并确认撤销、脏状态和多标签隔离。
3. **实现列块粘贴**：单行复制到每个选择行，多行等量逐行粘贴，不匹配安全拒绝。
4. **实现数字序列填充首版**：按选择行顺序写入十进制 `1..n`，后续再决定自定义参数。
5. **集成验收与文档收尾**：完整回归、macOS 真实交互验收，规格状态改为已完成，README 同步。
