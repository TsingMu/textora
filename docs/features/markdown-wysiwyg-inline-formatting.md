# Markdown WYSIWYG 内联格式编辑

> 状态：已完成（2026-08-14）

## 背景与目标

Textora 的 Markdown WYSIWYG 已支持标题、段落、列表、引用、fenced code block 等块级结构，但块内文本仍由普通文本控件编辑。真实应用验收中发现，列表项里的 `**状态**` 仍显示星号，反引号包裹的路径仍显示反引号；粗体和行内代码等 Markdown 内联格式没有呈现为对应视觉样式，用户仍需在标记与内容之间来回映射。

本功能目标是在保持 Markdown 源码为唯一权威数据源的前提下，让常用内联格式在 WYSIWYG 中隐藏语法标记、按样式显示并可直接编辑。切回源码、Preview 或保存时，仍得到可理解、可继续编辑的 Markdown 源码；解析失败或暂不支持的写法必须保留原文，不得静默丢失内容。

## 范围

- 首期支持五类常用内联格式：
  - 粗体：`**text**` 与 `__text__`
  - 斜体：`*text*` 与 `_text_`
  - 删除线：`~~text~~`
  - 行内代码：反引号 code span
  - 链接文本：`[label](destination)`
- 在 WYSIWYG 的标题、普通段落、无序/有序/任务列表项和引用中按样式呈现上述格式，并隐藏 `**`、反引号、方括号等语法标记。
- 用户可直接编辑已有格式片段内的可见文字；修改继续进入当前 Markdown 源码、脏状态、撤销、保存和关闭保护链路。首期不提供创建、移除或切换格式的命令。
- 链接显示为链接样式和可见标签，但不得点击导航、打开外部浏览器或加载目标资源。
- fenced code block、代码语言标记、源码岛和原始 HTML 中的相似字符保持字面文本，不解析为内联格式。
- 不完整、歧义、转义或暂不支持的内联语法安全退化为字面文本，并保持原始源码可恢复。

## 非范围

- 图片加载或图片所见即所得编辑。
- 原始 HTML 执行或渲染为可交互 DOM。
- 脚注、数学公式、目录、标签、提及、emoji shortcode 或插件语法。
- 点击链接导航、自动访问链接、下载远程资源或读取链接指向的本地文件。
- 在 fenced code block、inline code span 内继续解析粗体、斜体、删除线或链接。
- 格式工具栏、Markdown 格式快捷键、悬浮菜单、通过选区创建/移除格式，以及完整富文本粘贴。
- 在 WYSIWYG 中查看或修改链接目标；首期只允许编辑链接标签，目标源码保持原样。
- 改变 Markdown 文件编码、换行、保存目标、Rust 文档核心、Tauri capability、网络或 shell 权限。

## 用户流程

1. 用户打开包含常用内联格式的 Markdown 文档并切换到 WYSIWYG。
2. 标题、段落、列表项和引用中的粗体、斜体、删除线、行内代码与链接文本按对应样式显示，Markdown 标记隐藏。
3. 用户在已有格式片段中直接修改可见文字，格式语义保持。
4. 用户切回源码或 Preview，看到与编辑结果一致的 Markdown 源码或派生预览。
5. 用户保存文档，磁盘中仍只有 Markdown 源码，不包含 WYSIWYG DOM 或样式产物。

示例：

| Markdown 源码 | WYSIWYG 预期 |
| --- | --- |
| `**状态**：待开始` | “状态”显示为粗体，不显示 `**` |
| `_注意事项_` | “注意事项”显示为斜体 |
| `~~已取消~~` | “已取消”显示删除线 |
| ``使用 `docs/tasks/current.md` `` | 路径显示为行内代码，不显示反引号 |
| `[Textora](https://example.invalid)` | “Textora”显示为链接样式，但点击不导航 |

## 行为规则与边界情况

- Markdown 源码仍是唯一权威数据源；内联节点、选择状态和 WYSIWYG DOM 均为可重建派生状态。
- 只在 WYSIWYG 已支持的结构化文本块中解释内联格式；源码岛、fenced code 和代码语言标记必须保持字面源码。
- 行内代码内容优先按字面文本处理，其中的星号、下划线、波浪线、方括号和 HTML 不得继续解释或执行。
- 链接目标必须作为非导航数据保存；渲染链接标签时不得创建 `href` 或其他可导航属性，不得把目标放进可触发系统打开行为的控件。首期不在 WYSIWYG 中显示或修改目标，编辑标签后必须逐字符保留原目标源码。
- 首期解析允许相邻的五类格式片段，但不解释格式片段内部的嵌套语法；inline code 始终是叶节点，其中所有字符均按字面显示。格式片段内部再次出现强调、删除线、链接或无法确定边界的交叉/重叠标记时，整个相关片段退化为字面源码，不猜测嵌套关系。
- 反斜杠转义的标记不启动格式；code span 使用长度相同的成对反引号作为边界并保留内部文本，不执行 HTML 或空白规范化。无法找到确定闭合边界时按字面源码处理。
- 首期链接只识别同一结构化文本块内边界明确的 `[label](destination)`；标签不能为空、不得包含嵌套链接，带 title、边界不平衡或目标范围无法确定的写法退化为字面源码。目标是否为 URL、相对路径或本地路径不影响其非导航行为。
- 用户编辑已有格式片段时，不得因光标移动、选区跨越边界、空内容或删除首尾字符而丢失相邻普通文本。
- 未编辑片段必须逐字符保留原始源码，包括 `**`/`__`、`*`/`_`、大小写、转义与链接目标。编辑已有片段时优先沿用原开闭标记；若新文字会与原标记冲突，序列化器应执行保持可见文字所需的最小转义，code span 可改用能包住内容的最短更长反引号边界。片段内容被删空时只删除该片段及其格式标记，不删除相邻文本。
- 无法可靠解析或往返的输入应保持字面源码，必要时让当前片段退化为安全的源码编辑表现；不得猜测并重写内容。
- 切换 WYSIWYG、Preview、源码模式或标签时，内联格式内容和选择状态不得污染其他标签；迟到事件不得写入非活动文档。
- 只读、加载、保存、冲突、文件缺失、关闭确认和另存为面板期间，内联格式编辑与现有 WYSIWYG 控件一样被锁定。
- 大文件与失败退化规则沿用 `docs/features/markdown-wysiwyg-mode.md`；增强失败不得阻止源码查看、编辑或保存。

## 已确认决议

- 首期只显示并编辑已有格式片段，不提供创建、移除或切换格式的工具栏、快捷键或弹层。
- 首期允许相邻格式，不解释嵌套或交叉格式；inline code 为叶节点，无法确定的范围整体安全退化为字面源码。
- 链接以无 `href` 的非导航样式显示，只编辑标签；目标不在 WYSIWYG 中显示或修改并逐字符保留。
- 未编辑片段逐字符保留；编辑片段优先沿用原分隔符，仅在保持可见文字所需时执行最小转义或调整 code span 反引号长度。
- 富文本格式命令、链接目标编辑、嵌套格式和主动规范化均需另立后续规格，不由本功能自动扩张。
