# Markdown WYSIWYG 表格展示与编辑

> 状态：已完成（2026-11-02，T02-01～07 已获 Codex 确认及父模块验收）；r1（2026-10-29）。用户已确认首期范围；下列边界与交互细则是本轮规划约定，不表示用户逐项指定。

## 背景、来源与范围

用户截图中的表格显示为浅底虚线框内的 Markdown 原文。现有 WYSIWYG 规格明确将表格作为源码岛，代码与该范围一致；本功能是扩展已有能力。用户于 2026-10-29 要求按 CSF 规划，并确认“已有表格可视化、单元格编辑、增删行列及列对齐；新建表格、合并单元格、拖拽和 Excel 多单元格粘贴暂不包含”。随后用户于 2026-11-02 授权实施第一项。

- **FR-1**：已有、受支持的顶层 Markdown 管道表格呈现为真实表头、行、列；单元格支持现有五类内联格式的显示。
- **FR-2**：直接编辑表头及数据单元格的文字，包括空单元格、已有粗体/斜体/删除线/code/link 片段；链接只编辑标签、不导航。编辑结果同步源码、脏状态、保存与模式切换。
- **FR-3**：在数据行前后插入空行、删除指定数据行。
- **FR-4**：在指定列左右插入空列、删除指定列；表头、分隔行和所有数据行同步变化。
- **FR-5**：设置指定列的默认、左、居中或右对齐，WYSIWYG 与 Preview 一致。

## 非范围

不提供空文档新建表格、表格模板、合并/拆分单元格、拖拽/排序/列宽持久化、整表删除、表头行删除、多单元格选区、Excel/TSV 矩阵粘贴、富文本转换、公式、嵌套表格、单元格内块级 Markdown 或硬换行。不增加内联格式创建/切换命令、链接目标编辑或文档级撤销系统。不改 Rust、文件编码/换行策略、IPC 或权限。

## 行为与边界约定

- **BR-1 / 受支持子集**：顶层表格至少一列表头和同列数分隔行；分隔单元为三个以上 `-`、可带左右 `:`。支持外侧管道可有可无、空单元格、仅表头无数据行。数据行列数必须与表头相同；不补齐或截断。行内实际换行结束该行。列表/引用内的表格不新增结构化支持。
- **BR-2 / 管道与失败退化**：按反斜杠奇偶区分分隔管道与 `\|` 字面管道；此规则同样适用于行内代码中的管道。未转义的 `|` 总是列分隔符，不凭反引号猜测跨列合并。无法可靠识别边界、行列不齐或不支持的写法保留源码岛/既有字面表现，不能吞掉后续正文。HTML 按文字，不执行；图片不加载，链接不导航。
- **BR-3 / 源码保护**：只切模式不改源码或脏状态。单元格编辑只改变目标单元格源码；列对齐只改变目标分隔单元。增删行只改变目标行及必要换行；增删列可重建当前表格为规范管道格式，但未编辑单元格的原始内联源码必须保留。所有操作均逐字符保留表格外源码、相邻空行、末尾换行与其他表格；编辑非表格块也不得重写未编辑表格。既有规范中“未编辑块不得静默重写”的承诺继续有效。
- **BR-4 / 单元格输入**：软换行仅是视觉效果。Enter 不创建行或硬换行；IME 候选确认不被拦截。粘贴只取纯文本，CR/LF 合为空格，Tab 转为空格，不解释为矩阵；输入 `|`、反斜杠或反引号不能改变列数或泄漏到相邻单元。保留既有片段格式；格式内容删空后仍留下可聚焦的空单元编辑入口。原生控件文字撤销只承诺现有能力，必须实测；结构操作不承诺撤销，以 BR-5 的确认保护为门禁。
- **BR-5 / 结构操作保护**：以当前聚焦单元确定目标，控件具有明确文字/无障碍名称。可在表头下方插入第一条数据行；最后一条数据行可删除为仅表头；表头行不能删除，最后一列不能删除。删除任何非空行/列（列包括表头）前就地确认，显示目标及内容将被删除；取消不改源码、不改脏状态。空行/空列可直接删。焦点移动到相邻有效单元；无数据行时移到表头。待确认期间其他结构动作不可叠加，切换标签/模式、源码更新或进入锁定态时取消旧确认，不允许迟到确认删除新内容。
- **BR-6 / 对齐**：默认 `---`、左 `:---`、居中 `:---:`、右 `---:`。不操作时保留原分隔写法；显式修改仅规范化目标分隔单元，表头与数据视觉对齐同步。新列默认对齐，行操作不改列对齐。
- **BR-7 / 布局与焦点**：长中文、路径和 code span 可软换行；宽表在局部容器横向滚动，不撑宽整个编辑器，720px 窗口内工具可达。支持明暗外观、键盘进入编辑与操作控件；Tab/Shift+Tab 在同一单元多个内联片段间按原生顺序移动，随后到相邻可编辑项/操作控件，表尾不自动新增行，不劫持箭头键或系统快捷键。增删行列后按 BR-5 恢复焦点。
- **BR-8 / 会话与失败**：只读、加载、保存、冲突、缺失、关闭确认和另存为期间均禁止修改，包括待确认动作；标签切换和外部更新后旧输入/组合/确认事件不得写入新文档。更新必须核对标签与源码快照。失败保留现有源码，可回源码模式继续编辑。单文件仍遵守 50 MiB 上限，不能因为表格增加无限循环或整文档二次解析重试。
