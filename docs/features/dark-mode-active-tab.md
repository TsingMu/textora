# 暗色模式下区分活动标签

> 状态：已确认（2026-10-23 整理草案，2026-10-24 用户确认）

## 背景与目标

在 macOS 暗色模式下，当前活动标签与其他标签的视觉差异太弱，用户难以快速判断编辑器正在展示哪个文件。目标是在多标签会话中让活动标签无需悬停或读取状态栏即可被清楚识别，同时保持现有标签切换行为。

## 范围

- **FR-1**：暗色模式的标签栏对活动标签提供稳定、明显的选中视觉状态；非活动标签相对退后。区分不能仅依赖悬停或未保存标记。
- **FR-2**：新建、打开、恢复、切换或关闭标签导致活动项变化时，视觉状态立即跟随唯一活动标签；标签名、关闭按钮及未保存标记仍清晰可读。
- **FR-3**：macOS 在应用运行时切换浅色/暗色外观，标签状态随外观更新且仍能辨识；浅色模式原有活动/非活动区分保持有效。

## 非范围

- 重做标签栏布局、改变标签顺序、拖拽排序或标签状态模型。
- 增加用户可配置主题、手动配色方案或自定义强调色。
- 更改编辑器内容、高亮主题、预览样式或文件保存行为。

## 用户流程

1. 用户在暗色模式下同时打开至少两个标签。
2. 不悬停任何标签时，用户能直接识别与编辑器内容对应的活动标签。
3. 用户点击另一个标签或通过打开、关闭等操作改变活动标签；新的活动项明显突出，旧活动项退回非活动状态。

## 行为规则与边界情况

- **BR-1**：选中状态由真实活动标签决定；任一时刻至多一个标签呈现活动视觉状态，不能因异步打开、恢复或标签切换留下多个高亮项。
- **BR-2**：活动与非活动至少在标签表面和边界/强调标识上形成可辨差异；文字对比和脏状态标记不应因选中样式失去可读性。具体颜色值属于设计与实现选择。
- **BR-3**：悬停、键盘焦点、禁用及未保存状态可与选中状态并存，但不能掩盖当前活动项；不只靠颜色相近的细微色差表达选中。
- **BR-4**：现有标签的可访问选中语义和点击/关闭交互保持准确。

## 验收条件

- [x] **AC-1**：macOS 暗色模式下至少三个标签并列，静止且无悬停时，活动标签可凭标签本身明显辨认，非活动标签不会被误认为选中。
- [x] **AC-2**：依次切换、打开新文件、关闭活动标签和启动恢复后，视觉活动项与实际编辑内容始终一致且只有一个。
- [x] **AC-3**：活动或非活动标签出现长文件名、未保存标记、悬停、键盘焦点及禁用状态时，标签名、关闭操作和活动状态均可辨。
- [x] **AC-4**：运行中切换浅色/暗色外观后，两种模式均可辨认活动标签；现有标签切换、关闭和可访问状态不回归。
- [x] **AC-5**：完成相关组件/状态自动化回归，并在 macOS 真实应用中对浅色、暗色模式进行目视验收。
