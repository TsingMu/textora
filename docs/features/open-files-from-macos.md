# 从 macOS 拖放与文件关联打开文档

> 状态：已完成（2026-10-24 通过全部验收；本期采用单文件范围，多文件作为后续扩展）

## 背景与目标

目前只能在 Textora 内使用“打开”入口和系统文件面板选择文件。用户希望把 Finder 中的文件拖入应用窗口直接打开，并能在 macOS 中把 Textora 选为 `.md` 文件的默认打开应用，使双击文件也能进入现有编辑会话。两个入口应沿用已有的文件安全、标签和错误处理规则。

## 范围

- **FR-1 窗口拖放**：用户将 Finder 中的单个本地文件拖到 Textora 主窗口时，应用接收该文件并打开；拖放目标不要求精确落在编辑器或标签栏。拖放是“打开文件”，不得把路径或文件内容插入当前编辑文档。
- **FR-2 macOS 文件关联**：Textora 作为 `.md` 文档的可选打开应用出现在 macOS“打开方式”中。用户可在 Finder 中将其设为 `.md` 的默认应用；设定后，双击 `.md` 文件可打开 Textora 并展示该文件。仅提供可选能力，不在安装或启动时擅自更改系统默认应用。
- **FR-3 运行状态**：应用未运行时由文件启动，以及应用已运行时从 Finder“打开方式”或双击发送文件，都应在主窗口中展示目标文件并使其成为活动标签。
- **FR-4 会话一致性**：成功打开未在会话中的文件时新增并切换到文件标签；同一路径或符号链接别名已打开时切换到已有标签，不重复读取或覆盖其未保存内容。原有未保存标签和其他标签保持不变。
- **FR-5 失败反馈**：不支持、无权限、缺失、超过 50 MiB、编码无效或读取竞争等失败沿用现有打开错误语义，明确告知用户，且不创建半成品标签或改变现有文档。

## 非范围

- 一次拖入或由 Finder 一次交付多个文件的批量打开；本规格仅承诺单文件流程。
- 拖放文件夹、目录树、Dock 图标投放，以及从浏览器、邮件等应用直接拖放非文件内容。
- 自动将 Textora 设置为系统默认应用；`.markdown`、`.txt` 等其他扩展名的系统关联。
- 改变编码检测、大小限制、保存行为、启动恢复内容或多窗口模式。

## 用户流程

1. 用户从 Finder 拖入一个文件到 Textora 主窗口；或者在 Finder 将 Textora 选为 `.md` 的打开应用，然后双击 `.md` 文件。
2. Textora 接收操作系统交付的文件，按已有规则检查并读取。
3. 成功时主窗口显示并激活文件标签；再次打开已在会话中的文件则激活原标签。
4. 失败时显示可理解的错误，现有标签和未保存编辑保持原样，用户可继续操作或重试。

## 行为规则与边界情况

- **BR-1**：只有来自系统实际文件打开或拖放事件的本地文件可进入该流程；不得把前端可任意提交的路径变成通用读文件能力。正文继续使用现有 Rust 文档核心和二进制内容通道。
- **BR-2**：拖放与 Finder 打开请求和现有“打开”入口共享文件身份、大小、编码、只读、外部变更及保存冲突规则。
- **BR-3**：应用冷启动时，来自 Finder 的文件请求不得被上次会话恢复覆盖或丢失；目标文件已在恢复清单中时只保留一个标签，最终活动标签为本次请求的文件。恢复期间如暂不能打开，应待可安全处理后再执行。
- **BR-4**：保存目标选择、冲突/缺失处理、关闭确认等模态过程不应被新文件请求打断或使结果归属错误标签；待模态结束后安全处理请求。窗口关闭或退出已获用户确认时不得因迟到请求重开或修改会话。
- **BR-5**：拖放未形成可打开的单个本地文件时，不修改当前文档；应以明确、非破坏性方式拒绝。

## 验收条件

- [x] **AC-1**：在 macOS 真实应用中，将一个可支持的 UTF-8/CP936 本地文本文件从 Finder 拖入主窗口，出现内容正确的新活动标签；原有未保存标签内容不变，编辑器不会插入路径或拖放文本。
- [x] **AC-2**：在 Finder 的 `.md` 文件“打开方式”中可以选择 Textora 并设为默认；应用未运行和已运行两种情况下，双击文件均打开或激活正确标签。
- [x] **AC-3**：已打开文件及其符号链接别名通过任一新入口再次打开时，只激活原标签，原标签的未保存修改不被磁盘内容覆盖。
- [x] **AC-4**：冷启动同时存在会话恢复与 Finder 文件请求时，请求不丢失、不产生重复标签，最终显示请求文件；已有恢复文件按现有规则处理。
- [x] **AC-5**：打开失败、模态忙碌及非单个本地文件拖放不会破坏任何已打开或未保存文档；错误后可再次尝试。
- [x] **AC-6**：新入口不扩大前端通用文件系统、shell 或网络权限；自动化覆盖入口交付、重复文件、启动/模态时序与失败保护，macOS 打包应用完成真实拖放和 Finder 文件关联验收。
