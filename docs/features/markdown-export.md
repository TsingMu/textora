# Markdown 导出 PDF / DOCX

> 状态：已完成（2026-11-02；自动化、原生PDF/浏览器DOCX样例及兼容渲染验证）；2026-11-02；用户明确要求立即实施 PDF，并追加 Word doc/docx（选用可编辑 DOCX）。

- FR-1：Markdown 工具栏的 `Export…` 菜单提供 PDF 和 Word (.docx)；源码、Preview、WYSIWYG 均可使用当前内容快照，包含未保存内容。
- FR-2：PDF 复用 Preview HTML/样式，由 macOS 原生分页为 A4；仅导出文档，不含源码、工具栏和通知，浅色纸张，长文本换行，保留表格与表头样式，跨页排版由系统 WebKit 处理，不保证续页重复表头。
- FR-3：DOCX 保留可编辑标题、段落、常用文字格式、列表、引用、代码块和表格；字体/颜色接近 Preview，Word 分页可不同。Mermaid 转为本地图片；不输出假 .doc 文件。
- FR-4：本地渲染 Mermaid 完成后才导出；渲染错误明确反馈，不悄悄漏掉图。继承 Preview 的 HTML/图片/链接安全边界，不加载用户远程资源。
- BR-1：系统保存面板选择文件名/位置，默认原文件名加对应扩展名；取消无副作用。导出不改源码路径、编码、换行、脏状态或会话恢复记录。
- BR-2：导出忙碌期间禁重入并锁定相关操作；加载/保存/冲突/关闭确认等不开始导出；只读文档可导出。失败提示明确，仍可编辑保存原文。
- BR-3：输出仅由原生保存面板授权路径落盘，先临时文件完整生成，再原子替换；禁止覆盖已打开文档，取消/失败不损坏旧目标。无宽泛前端文件系统或 shell 权限。

验收：AC-1 两入口及取消/失败/锁定/快照与会话不变；AC-2 PDF 标题/中文/长列表/代码/表格/Mermaid/分页样式；AC-3 DOCX 同类内容可编辑并可打开，图表嵌入；AC-4 自动化、前后端构建及真实生成样例验证。

非范围：旧二进制 DOC、完整 Word 排版等价、任意 HTML/远程图片加载、文档导入、覆盖 Markdown 原文件或自动安装/发布。实现与验证证据以对应 RESULT 为准。

实现与验证见 `docs/tasks/T03-markdown-export/RESULT.md`；系统WebKit表头分页限制及未执行的Word本体/保存面板手工操作见子RESULT。
