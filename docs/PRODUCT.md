# 产品说明

## 定位

Textora 是一款 macOS 个人文本工作台，把用户在 Windows 内网工作中形成的文本处理习惯带到 macOS，为普通文本、代码、Markdown 和 Mermaid 提供统一的本地查看与编辑体验。

产品不以成为跨平台通用编辑器或公开市场上的 Notepad++、UltraEdit、Typora 替代品为目标。其首要价值是减少用户在 macOS 上为日常文本编辑、列块处理和 Markdown 工作流切换多个工具的需要，同时作为长期自用工具验证 AI 辅助开发方法。

## 目标用户

- 首要用户为项目作者本人：在 macOS 上频繁处理来自 Windows 与 Unix 环境的本地文本文件，并需要普通编辑、列块处理和 Markdown 工作流。
- 若未来自然扩展给其他用户，应优先服务具有相同文件兼容与编辑习惯的人群；外部用户增长不是当前产品成立的前提。

## 已确认范围

- macOS 13+ 桌面应用（Apple Silicon 与 Intel）
- 普通文本编辑
- 多文档编辑与会话管理
- 列块选择、批量删除、粘贴与数字序列填充
- 代码文本编辑
- Markdown 源码编辑、左右分栏预览，以及经独立规格确认后的所见即所得模式
- Mermaid 本地编辑与预览
- UTF-8、UTF-8 BOM 与 GBK/Windows CP936 文件
- LF、CRLF 与混合换行识别和可控转换
- 首版处理不超过 50 MiB 的单个文件

“支持”的具体深度（例如语法高亮、预览、实时渲染或导出）需由各功能规格定义，不能从上述范围自动推导。

## 产品原则

- 文本内容与用户文件安全优先，避免静默丢失或破坏内容。
- 基础编辑体验应保持直接、快速，增强功能不应阻塞普通文本编辑。
- 对文件编码、换行符或格式进行转换时，应让影响可理解且可控。
- Windows 来源文件兼容指编码、换行和编辑工作流兼容，不代表提供 Windows 版本。
- 功能优先级由真实自用频率与替代现有工具的价值决定，不以通用编辑器功能数量为目标。
- 新功能先形成可验证的最小垂直切片，再逐步扩展。

## 非目标

首版不包含 Windows 或 Linux 应用、GB18030、GB 级文件、十六进制编辑、LSP、协作或插件市场，也不以公开分发、商业化或外部用户增长为完成条件。

## 开放问题

- 是否以大文件编辑或项目目录浏览作为早期重点？
- 代码支持需要达到何种程度：仅高亮，还是包含语言服务、补全与诊断？
- Markdown 所见即所得如何在保持源码无损的前提下实现，并与左右分栏模式切换？
- Mermaid 预览需要支持哪些图表类型、导出方式与安全边界？
- 数字序列填充除起始值、步长和前导零外，是否需要十六进制、字母或日期序列？
